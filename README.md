# ausverkauf
A simple Python Website builder

## source syntax
- headings like markup
- images !(image name)
- paragraphs: any text -> <p></p>
- bold: **bold** -> <b></b>
- italic _ita _ licü._.wumpel -> <i></i>


## folders
### template
- css file
- html template with ##CONTENT place holder
### source
- source text
- imprint
- images
### site
- css file (copied)
- index.html (generated)
- images resized
